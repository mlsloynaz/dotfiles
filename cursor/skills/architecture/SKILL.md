# CLAUDE.md - Development Guidelines for ByDesign MLM Platform

This file provides Claude Code with essential context and best practices for the ByDesign multi-level marketing (MLM) platform codebase.

## Project Overview

This is a large-scale enterprise MLM platform with the following key components:

- **Frontend**: Angular 14+ applications (Shop, Revolution, BackOffice)
- **Backend**: .NET/C# SOA services, VB.NET legacy components
- **Database**: SQL Server with extensive stored procedures
- **Architecture**: Service-Oriented Architecture (SOA) with multi-client support
